This is a sample post. To publish a new one:

1. Create a file `resources/content/en/posts/<slug>.md` with the text in Markdown.
2. Add an entry to `resources/content/en/posts.json` with the same `slug`, a title, the date (`YYYY-MM-DD`) and a summary.

Posts are sorted by date automatically, newest first.
